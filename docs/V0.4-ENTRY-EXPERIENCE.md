# v0.4 Entry Experience

## Information architecture

```text
/                    Landing Page
       ↓
/dashboard           Executive Dashboard
       ↓
/overview            Signal Overview / detailed workspace
       ↓
/sources             Acquisition & watch rules
/library             Persistent Data Library
/signals             Raw / normalized signals
/review              Human Review
/research            Research workspace
/insights            Insight Knowledge Base
/opportunities       Opportunity board
/settings            System configuration
```

## Landing Page responsibility

The landing page explains what the system is before exposing operational complexity. It intentionally renders without the workspace sidebar. Its job is to communicate:

- evidence-backed consumer intelligence rather than generic social listening;
- persistent data and reusable evidence;
- human-in-the-loop validation;
- the four-stage workflow from collection to opportunity;
- the relationship between data, intelligence, knowledge, and decision layers.

Primary CTA: **Open executive dashboard**.

## Executive Dashboard responsibility

The dashboard is the high-level command center. It should answer five questions before the user enters the detailed workspace:

1. Is the data system healthy?
2. How much evidence do we currently hold?
3. What is changing fastest?
4. What requires a decision now?
5. Where is work waiting in the research pipeline?

The top summary is connected to `/api/dashboard`. When Supabase is configured it reads live counts from the persistent workspace. Without Supabase it explicitly labels the values as a demo dataset.

## Detailed workspace responsibility

`/overview` remains the analytical signal overview. It is intentionally separate from `/dashboard`: the dashboard is for orientation and decision priority; the signal overview is for deeper exploration.
